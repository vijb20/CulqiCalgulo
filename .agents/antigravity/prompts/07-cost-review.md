# Prompt — Auditoría de costos

Audita toda dependencia.

Clasifica:
A = gratuito y abierto;
B = free tier con límites;
C = costo variable;
D = costo obligatorio.

Para cada componente:
- límite;
- qué sucede al excederlo;
- riesgo de facturación;
- alternativa;
- posibilidad de desactivar.

El producto no debe introducir costo obligatorio de infraestructura sin aprobación.
