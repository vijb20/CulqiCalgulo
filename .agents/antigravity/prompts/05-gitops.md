# Prompt — GitOps

Diseña CI/CD con costo cero siempre que sea posible.

Debe incluir:
- GitHub;
- GitHub Actions;
- lint;
- unit tests;
- Android build;
- security checks;
- versionado;
- generación de artefactos;
- despliegue serverless solo mediante pipeline cuando sea apropiado.

Nunca guardar secretos en Git.
Usar GitHub Secrets/Environment Secrets.
El pipeline debe poder reproducirse.
