# Prompt — Release Readiness

No aprobar release hasta verificar:
- documentación;
- legal/privacidad;
- seguridad;
- sandbox/prod separation;
- secretos;
- observabilidad;
- rollback;
- migraciones;
- costos;
- límites del free tier;
- Webhook productivo;
- multi-device;
- backup/recovery.

Entregar checklist firmado por criterios verificables.
