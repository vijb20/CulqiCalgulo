# Prompt — Release

Prepara una release reproducible.

Verifica:
- build release;
- R8/ProGuard;
- configuración por ambiente;
- secretos fuera del repositorio;
- tests;
- versionCode/versionName;
- permisos mínimos;
- política de privacidad;
- comportamiento de anuncios;
- ausencia de datos sensibles en logs.

No publiques ni subas secretos.
