# Flujo de trabajo entre agentes

## Etapa 1 — Descubrir
Leer especificación, inspeccionar repositorio y revisar ADR.

## Etapa 2 — Diseñar
Proponer cambios mínimos y contratos.

## Etapa 3 — Implementar
Modificar solo el alcance acordado.

## Etapa 4 — Verificar
Tests + seguridad + costos.

## Etapa 5 — Integrar
Actualizar documentación y ADR.

## Etapa 6 — Entregar
Resumen:
- qué cambió;
- archivos;
- pruebas;
- riesgos;
- siguientes tareas.

## Regla de conflicto

Si Android Studio y Antigravity proponen soluciones distintas:
1. gana la seguridad;
2. luego MASTER_SPEC;
3. luego ADR;
4. si no existe ADR, crear uno antes de decidir.
